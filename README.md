> **Can you act like a movie character in just 5 seconds?**

## Project Description

**Wordnt** is a fun facial-expression imitation game where players are shown an expression from a film character and must imitate it within **5 seconds**.

The player's facial expression is analyzed using facial APIs, and an accuracy score is calculated. The game consists of **16 levels**, and the player's final score is calculated from all the levels.

---

## The Problem (that doesn't exist)

Have you ever looked at a movie character making a dramatic expression and thought:

> **"I can definitely make that face."** 😎

But how do you actually prove it?

There is no proper way to know whether your confused, angry, shocked, or dramatically emotional face is actually close to that of a movie character.

**This is clearly a problem that absolutely needed to be solved.**

---

## The Solution (that nobody asked for)

Introducing **Wordnt** — your completely unnecessary facial acting challenge. 🎭

The game presents the player with an expression of a film character.

The player gets only **5 seconds** to imitate the expression using their own face.

The webcam captures the player's expression and a facial API analyzes it to determine how closely the player matched the target expression.

Each successful attempt produces an **accuracy score**.

The game contains **16 levels**, with a different expression challenge at each level.

After completing all 16 levels, the scores are combined to calculate the player's **overall accuracy**.

If you survive all 16 levels...

## 🎉 YOU WIN THE GAME! 🎉
